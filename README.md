# 微贷慧查｜小微贷款贷前尽调辅助工具

**定位：银行内部AI创新应用比赛 · 规则核查演示原型（独立作品02）**

## 核心功能

1. **虚构小微企业资料录入**：一键选择收入差异、资料缺失、较完整三种演示案例，也可以手工修改。
2. **演示材料清单核对**：标出尚未录入的材料类别；不声称所有类别都为正式强制材料。
3. **经营数据交叉比较**：把申报年收入与模拟账户流入额、纳税销售额并列，提示数值差异及待核实口径。
4. **核查意见留存**：按模拟制度关联相关条款，写入人工复核备注。
5. **Word与Markdown导出**：生成供人工完善的核查记录草稿。

## 技术与边界

- Python + Streamlit + python-docx；没有接入AI大模型。
- 核查中的**20%差异线仅为演示触发值**，不是银行风险评级、授信准入、模型评分或监管规定。
- “流水”和申报营业收入可能存在统计期间、口径、现金回款、账户范围等差异；不能直接推断企业夸大经营收入。
- 所有数据均为虚构，规则引用的是从原“智规通”项目提取的单份模拟小微贷款制度。
- 不做授信决策、客户风险等级评定、贷后监测或任何真实客户信息处理。

## 本地运行

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## 与制度问答作品的区别

本作品专注**一个小微贷款贷前调查场景**，侧重企业资料核对和核查记录。系统里仅内置用于标注依据的模拟小微贷款制度，不提供通用银行制度问答。

## 独立部署到 Streamlit Community Cloud

1. 新建另一个GitHub仓库，例如 `microloan-dd-demo`。
2. 上传本文件夹里面的 `app.py`、`rules.py`、`report.py`、`data/`、`requirements.txt` 等到根目录。
3. 在 Streamlit Cloud 新建第二个App，连接新的GitHub仓库，主文件设置为 `app.py`。
4. 选择“收入差异案例”并点击“运行模拟资料核查”；下载Word检查格式。

> 与作品一分成两个不同的GitHub仓库和两个Streamlit网址。不要覆盖现有智规通仓库。

## 参赛现场三步演示

1. 选择“收入差异案例”（100万元贷款，500万元申报营业收入，280万元模拟账户流入）。
2. 运行核查，展示220万元差异、材料待补项、核对口径说明和模拟制度依据。
3. 补充人工复核意见，导出Word核查记录。
